Painel

Seu banco, direto do Java.

Crie contas com várias chaves Pix, faça transferências, invista e acompanhe o extrato. As regras de negócio rodam no mesmo código Java do projeto de terminal.

Como funciona a demo: cada visitante tem o próprio banco, guardado só na memória do servidor. Os dados somem depois de 30 minutos parado ou quando o servidor reinicia, e o total é limitado a R$ 1.000,00.
